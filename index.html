Gravitino

A high-performance, geo-distributed metadata catalog for data lakes. It unifies metadata across multiple clouds and regions, providing a single source of truth for your data assets.

HMS

The Hive Metastore (HMS) is the central repository of metadata for Hive tables and partitions in a relational database. It provides client access to this information via the Metastore service API.

Lakekeeper

A Rust-native, high-performance Iceberg REST Catalog. It is designed for speed and efficiency, providing a lightweight alternative to Java-based catalogs.

Nessie

A transaction-consistent data catalog for Data Lakes that brings Git-like semantics to your data. Nessie allows you to version your data, create branches, and merge changes atomically.
