# Kafka Terraform Modules

This directory contains Terraform modules for deploying Kafka components.

## Submodules

- [cluster](kafka-cluster.md): Deploys a Kafka cluster.
- [connect](kafka-connect.md): Deploys Kafka Connect.
- [ksqldb](kafka-ksqldb.md): Deploys KSQLDB.
- [node](kafka-node.md): Deploys a Kafka node.
- [schema-registry](kafka-schema-registry.md): Deploys the Schema Registry.
- [ui](kafka-ui.md): Deploys the Kafka UI.
